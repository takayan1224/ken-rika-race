# けん と りか の 6周レース

1周120mのコースを6周する「けん」と「りか」の動きを、時間を動かしながら確かめられる教材です。

- **シミュレーション**（`index.html`）… 陸上競技場のトラックを2人が走るようすと、道のり・ダイヤグラムのグラフ
- **解説スライド**（`slides.html`）… 問題の解き方のスライド（←→キーで前後、Fキーで全画面）

## 問題の設定

- けん：1周目は秒速6m、そこから1周ごとに秒速1mずつおそくなる
- りか：一定の速さで走り、4分で6周を走り終える

## 使い方

- 再生ボタンで時間が進みます。再生速度は ×¼〜×8 から選べます。
- 「イ」「ウ」「エ」のボタンで、追いぬきの場面に移動できます。
- グラフは「道のり（0〜720m）」と「ダイヤグラム（0〜120m）」を切り替えられます。
